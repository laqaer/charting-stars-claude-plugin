# Charting Stars for Claude

Calculate birth charts and check the current sky, Moon phase, Sun-sign horoscopes and sign compatibility.
Use the chart skill to handle unknown birth times and ambiguous places correctly.
Use the reading-order skill only when you choose to buy or track a written reading.

Connect `https://chartingstars.com/api/mcp?via=claude` with no authentication.
The package exposes seven tools. An order tool creates an unpaid draft.
Review and pay on the Charting Stars website. The assistant does not charge a card.
See [setup instructions](https://chartingstars.com/connector).
A custom installation does not mean that Anthropic has approved a directory listing.

Free requests use birth details for calculation without saving a chart.
Orders save confirmed birth details and the delivery email.
Logs record platform and tool names, without tool arguments.
See the [privacy policy](https://chartingstars.com/privacy) and [terms](https://chartingstars.com/terms).
Contact hello@chartingstars.com for support.
Astrology is for reflection and entertainment. It does not provide medical, legal or financial advice.
